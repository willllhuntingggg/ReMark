# ReMark

> Mark it now. Find it later.

ReMark 是一个基于 Chrome Extension Manifest V3 的本地知识收集扩展。它可以在网页中保存文字划线、为划线和视频时间点添加笔记、在 YouTube 与 Bilibili 视频中记录时间点，并在侧边栏中按来源页面归档、搜索、定位、删除或导出 Markdown。

## 产品定位

ReMark 面向需要快速保存网页信息和视频关键片段的用户。核心数据包括三类：网页划线、划线笔记，以及视频时间点和视频笔记。所有核心收集与管理能力都在浏览器本地运行，不依赖后台服务器，也不要求登录账号。

> 当前代码实现的是“划线、笔记、视频打点和 Markdown 导出”。虽然扩展描述中提到标签整理，但仓库中尚未形成标签的创建、编辑、筛选和持久化闭环，因此标签不属于当前可验收功能。

## 功能概览

| 能力 | 当前行为 |
|---|---|
| 保存网页文字 | 在网页中选中至少 2 个字符后按 Command/Ctrl，或使用上下文菜单保存并高亮。 |
| 恢复划线 | 重新访问来源页面时，尝试根据已保存原文恢复高亮。 |
| 添加笔记 | 可分别为网页划线和视频打点新增、修改或清空笔记。 |
| 视频打点 | 支持识别 YouTube 与 Bilibili 视频，并记录当前播放时间。 |
| 打点快捷方式 | 视频页面提供“打点”能力，也支持 Command/Ctrl+M；输入框、文本框和可编辑区域获得焦点时不会触发。 |
| 剪藏库 | 在侧边栏中按 URL 分组展示划线和视频打点，按最近创建时间排序。 |
| 搜索 | 搜索划线原文、划线笔记和页面标题；视频打点本身不参与文本搜索。 |
| 定位 | 从侧边栏打开来源页面并定位到划线或视频时间点。 |
| 删除 | 支持删除单条划线、单个视频打点或某页面下的全部剪藏。 |
| 导出 | 选择页面后导出 Markdown，包含来源、划线、笔记、视频标题和时间点。 |

## 安装与运行

当前仓库没有构建脚本或依赖安装步骤，适合直接以 Chrome 的“加载已解压的扩展程序”方式运行。

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录，即包含 `manifest.json` 的目录。
5. 打开任意网页，点击扩展图标打开 ReMark 侧边栏；也可以在仓库中的 `index.html` 页面进行基础功能测试。

修改代码后，在扩展管理页面点击 ReMark 的刷新按钮，再重新打开目标网页或刷新网页，以确保内容脚本加载最新版本。

## 快速使用

### 保存网页划线

在任意网页中选中一段至少两个字符的文字，然后按住 Command 或 Ctrl 完成选择。ReMark 会保存该文字并在页面中显示高亮。另一种方式是在选中文字后打开浏览器上下文菜单，选择“划线高亮并保存 (ReMark)”。

### 添加划线笔记

点击扩展图标打开侧边栏，在对应划线的笔记区域添加文字并保存。已有笔记可以再次编辑；保存空白内容会清除该笔记。

### 记录视频时间点

在 YouTube 或 Bilibili 视频页面播放到目标位置后，使用页面中的“打点”能力，或在不处于输入状态时按 Command/Ctrl+M。已保存时间点会出现在视频进度条和侧边栏中。再次点击进度条上的打点，或从侧边栏打开该打点，可以回到对应时间。

同一视频在相差小于 1 秒的位置重复记录时，ReMark 不会创建新的打点，而是使用已有打点。

### 搜索、删除和导出

在侧边栏搜索框中输入关键词，可以匹配划线原文、划线笔记和页面标题。用户可以删除单条划线、单个视频打点或一个页面下的全部剪藏。选择一个或多个页面后，点击 Markdown 导出即可下载带时间戳文件名的 `.md` 文件。

## 数据与隐私

ReMark 使用 Chrome 的本地存储保存设置、划线和视频打点。代码同时提供浏览器本地存储的兼容回退路径。当前实现没有登录、远程数据库或后台同步能力，因此清除浏览器扩展数据、迁移浏览器配置或卸载扩展可能导致本地剪藏不可用；使用导出功能备份重要内容。

首次初始化时，代码会写入默认设置，并在尚无划线数据时创建两条演示划线，用于快速体验侧边栏和导出功能。演示数据属于本地初始化数据，不代表用户实际访问过对应页面。

## 权限说明

扩展声明了本地存储、当前活动标签页、标签页查询与切换、脚本相关能力、侧边栏和上下文菜单权限。内容脚本匹配所有 URL，以便在任意网页中识别文字选择，并在受支持的视频站点中提供视频打点能力。权限范围由 `manifest.json` 定义；如果未来缩小功能范围，应同步评估并收紧权限。

## 已知边界

当前划线恢复依赖页面正文中仍能找到与历史记录一致的文字，因此页面改版、文字变化、动态加载或复杂 DOM 结构可能导致高亮无法自动恢复，但不会删除本地记录。

视频打点依赖可识别的视频元素和平台进度条。当前实现针对 YouTube 和 Bilibili 做了平台识别，不应将其描述为对所有视频站点的通用支持。

当前搜索只覆盖页面标题、划线原文和划线笔记，不搜索视频标题、视频时间点或视频笔记。导出是一次性的 Markdown 文件下载，不包含云端同步、自动备份或反向导入功能。

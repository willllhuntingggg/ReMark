# ReMark

> Mark it now. Find it later.

ReMark 是一个基于 Chrome Extension Manifest V3 的本地知识收集扩展。它可以在网页中保存文字划线、为划线和视频时间点添加笔记、在 YouTube 与 Bilibili 视频中记录时间点，并在侧边栏中按来源页面归档、搜索、定位、删除或导出 Markdown。

## 产品定位

ReMark 面向需要快速保存网页信息和视频关键片段的用户。核心数据包括三类：网页划线、划线笔记，以及视频时间点和视频笔记。所有核心收集与管理能力默认在浏览器本地优先运行（Local-first 本地优先架构），不依赖后台服务器，不强制要求登录账号。

在 v1.1.0 中，ReMark 新增了可选的 Google 账号登录与 Supabase 云备份能力：用户可按需登录，本地数据会自动防抖异步备份至云端；在重装或更换设备后登录，可一键拉取云端备份完整恢复，保障数据资产安全。

> 当前代码实现的是“划线、笔记、视频打点、云备份与 Markdown 导出”。虽然扩展描述中提到标签整理，但仓库中尚未形成标签的创建、编辑、筛选和持久化闭环，因此标签不属于当前可验收功能。

## 功能概览

| 能力 | 当前行为 |
|---|---|
| 保存网页文字 | 在网页中选中至少 2 个字符后按 Command/Ctrl 保存并高亮。 |
| 恢复划线 | 重新访问来源页面时，尝试根据已保存原文恢复高亮。 |
| 添加笔记 | 可分别为网页划线和视频打点新增、修改或清空笔记。 |
| 视频打点 | 支持识别 YouTube 与 Bilibili 视频，并记录当前播放时间。 |
| 打点快捷方式 | 视频页面提供“打点”能力，也支持 Command/Ctrl+M；输入框、文本框和可编辑区域获得焦点时不会触发。 |
| 首次使用教学 | 首次使用时通过简短动画或静态兜底说明 Command/Ctrl 划选文字的操作方式。 |
| 剪藏库 | 在侧边栏中按 URL 分组展示划线和视频打点，按最近创建时间排序。 |
| 搜索 | 搜索划线原文、划线笔记和页面标题；视频打点本身不参与文本搜索。 |
| 定位 | 从侧边栏打开来源页面并定位到划线或视频时间点。 |
| 删除 | 支持删除单条划线、单个视频打点或某页面下的全部剪藏。 |
| 云备份与恢复 | 支持自选 Google 登录，数据变动自动异步备份至 Supabase 云端；新设备/重装登录后可一键拉取完整恢复。 |
| 导出 | 选择页面后导出 Markdown，包含来源、划线、笔记、视频标题和时间点。 |

## 安装与运行

当前仓库没有构建脚本或依赖安装步骤，适合直接以 Chrome 的“加载已解压的扩展程序”方式运行。

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库根目录，即包含 `manifest.json` 的目录。
5. 打开任意网页，点击扩展图标打开 ReMark 侧边栏；也可以在仓库中的 `index.html` 页面进行基础功能测试。

修改代码后，在扩展管理页面点击 ReMark 的刷新按钮，再重新打开目标网页或刷新网页，以确保内容脚本加载最新版本。

## 快速使用

### 保存网页划线

在任意网页中选中一段至少两个字符的文字，然后按住 Command 或 Ctrl 完成选择。ReMark 会保存该文字并在页面中显示高亮。首次使用时，扩展应通过简短教学动画说明“选择文字—按住快捷键—产生高亮”的操作顺序；如果动画不可用，则提供静态文字或图示作为兜底。

### 添加划线笔记

点击扩展图标打开侧边栏，在对应划线的笔记区域添加文字并保存。已有笔记可以再次编辑；保存空白内容会清除该笔记。

### 记录视频时间点

在 YouTube 或 Bilibili 视频页面播放到目标位置后，使用页面中的“打点”能力，或在不处于输入状态时按 Command/Ctrl+M。已保存时间点会出现在视频进度条和侧边栏中。再次点击进度条上的打点，或从侧边栏打开该打点，可以回到对应时间。

同一视频在相差小于 1 秒的位置重复记录时，ReMark 不会创建新的打点，而是使用已有打点。

### 搜索、删除和导出

在侧边栏搜索框中输入关键词，可以匹配划线原文、划线笔记和页面标题。用户可以删除单条划线、单个视频打点或一个页面下的全部剪藏。选择一个或多个页面后，点击 Markdown 导出即可下载带时间戳文件名的 `.md` 文件。

### 账号登录与云备份 (可选)

点击侧边栏右上角设置图标（齿轮）进入设置面板，点击“使用 Google 登录”即可绑定账号。登录后，本地任何添加划线、编辑笔记、打点操作均会在 1.5 秒内自动防抖静默备份至云端。当在其他电脑或重新安装扩展后，点击“从云端恢复”即可一键下载云端快照恢复本地数据。用户亦可随时点击“立即备份”触发手动备份，或点击“退出登录”断开云端关联（本地数据依然完整保留）。

## 数据与隐私

ReMark 坚持 **本地优先（Local-first）** 原则：

1. **默认纯本地**：未登录状态下，所有设置、划线和视频打点仅保存在浏览器本地（`chrome.storage.local`），不向任何外部服务器发送数据。
2. **可选云端备份**：用户可自愿选择登录 Google 账号启用云备份。备份数据存储于 Supabase 托管的 PostgreSQL 数据库中，严格启用了行级安全策略（Row-Level Security, RLS），仅通过身份验证的本人账号具备对应数据的读写权限，无法越权访问他人数据。
3. **零追踪与透明**：扩展不包含任何第三方统计、追踪 SDK 或广告代码，不收集用户浏览历史与剪藏以外的内容。详细隐私声明参见 [`PRIVACY.md`](PRIVACY.md)。

首次初始化时，代码会写入默认设置，并在尚无划线数据时创建两条演示划线，用于快速体验侧边栏和导出功能。演示数据属于本地初始化数据，不代表用户实际访问过对应页面。

## 项目结构

| 路径 | 职责 |
|---|---|
| `manifest.json` | 声明 Manifest V3 扩展、权限、内容脚本、侧边栏和后台 Service Worker。 |
| `background.js` | 配置点击扩展图标打开侧边栏，调度自动云备份及转发后台消息。 |
| `content/content.js` | 处理网页文字选择、划线恢复与定位，以及 YouTube/Bilibili 视频打点。 |
| `content/content.css` | 提供网页高亮、视频打点、提示和动画样式。 |
| `lib/storage.js` | 封装本地数据读写，以及划线、视频打点、页面分组和设置操作。 |
| `lib/supabase.js` | Supabase 认证与轻量云备份客户端（原生 Web Crypto PKCE OAuth 与 PostgREST）。 |
| `lib/i18n.js` | 多语言国际化配置与文案管理。 |
| `sidepanel/sidepanel.html` | 侧边栏页面结构，包含剪藏列表、设置面板与云备份卡片。 |
| `sidepanel/sidepanel.js` | 侧边栏数据加载、展示、搜索、笔记编辑、删除、定位、Markdown 导出与云备份交互。 |
| `sidepanel/sidepanel.css` | 侧边栏视觉样式。 |
| `index.html` | 用于快速测试的示例页面，包含可被选中的示例文本。 |
| `assets/` | 扩展图标及其他静态资源。 |

## 权限说明

扩展声明了本地存储（storage）、当前活动标签页（activeTab）、标签页查询与切换（tabs）、脚本执行能力（scripting）、侧边栏（sidePanel）、导航与右键菜单（webNavigation, contextMenus）以及身份认证（identity）权限。其中 `identity` 权限仅用于调用 `chrome.identity.launchWebAuthFlow` 实现标准的 Google OAuth 登录认证流程。内容脚本匹配所有 URL，以便在任意网页中识别文字选择，并在受支持的视频站点中提供视频打点能力。

## 已知边界

当前划线恢复依赖页面正文中仍能找到与历史记录一致的文字，因此页面改版、文字变化、动态加载或复杂 DOM 结构可能导致高亮无法自动恢复，但不会删除本地记录。

视频打点依赖可识别的视频元素和平台进度条。当前实现针对 YouTube 和 Bilibili 做了平台识别，不应将其描述为对所有视频站点的通用支持。

当前搜索只覆盖页面标题、划线原文和划线笔记，不搜索视频标题、视频时间点或视频笔记。

云备份以“本地优先、整库快照”为设计目标，保障用户在重装或更换设备时能完整找回数据；当前版本不支持多设备间实时双向合并冲突解决（Conflict Resolution）。

# 导出与数据 User Stories

## US-16：选择页面并导出 Markdown

**User Story**  
作为用户，我希望选择一个或多个页面导出为 Markdown，以便在其他知识管理工具中继续使用。

**Acceptance Criteria**

- **Given** 剪藏库中存在至少一个页面，**When** 用户选择一个或多个页面并执行导出，**Then** 系统下载一个 Markdown 文件。
- **Given** 选中的页面包含划线，**When** 导出完成，**Then** Markdown 包含页面标题、来源链接、划线原文以及非空笔记。
- **Given** 选中的页面包含视频打点，**When** 导出完成，**Then** Markdown 包含视频标题、时间点、可用的视频时长和非空笔记。
- **Given** 用户开启“全选当前显示的页面”，**When** 搜索结果正在生效，**Then** 只选择当前搜索结果中的页面，而不是隐藏页面。
- **Given** 没有选中页面，**When** 用户尝试导出，**Then** 系统不生成空的导出文件。

## US-17：本地保存剪藏数据

**User Story**  
作为用户，我希望剪藏数据保存在当前浏览器本地，以便无需后台服务也能持续使用并减少数据离开设备的风险。

**Acceptance Criteria**

- **Given** 用户创建、修改或删除划线、笔记或视频打点，**When** 操作完成，**Then** 变更在浏览器本地保存，并可在重新打开扩展后读取。
- **Given** 扩展运行环境提供 Chrome 本地存储，**When** 用户使用 ReMark，**Then** ReMark 不要求用户登录或连接后台服务才能完成核心收集和管理功能。
- **Given** 本地数据不存在，**When** 用户首次初始化扩展，**Then** 系统初始化默认设置，并按当前代码提供演示划线数据。

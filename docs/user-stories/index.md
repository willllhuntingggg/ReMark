# ReMark User Stories

本文档将 ReMark 的需求按功能域拆分为独立文件。每条 User Story 只描述一个可独立验收的用户价值，并与一组 Given / When / Then 验收标准成对出现。内容聚焦需求和业务结果，不规定技术实现或具体页面交互细节。

## 文件索引

| 功能域 | 文件 | 覆盖内容 |
|---|---|---|
| 首次使用 | [`onboarding.md`](onboarding.md) | 打开侧边栏、首次使用快捷键划选教学。 |
| 网页划线 | [`web-clipping.md`](web-clipping.md) | 创建、恢复、定位和管理网页划线及划线笔记。 |

| 导出与数据 | [`export-and-data.md`](export-and-data.md) | Markdown 导出、本地保存与数据边界。 |

## 角色与术语

| 术语 | 定义 |
|---|---|
| 用户 | 使用 ReMark 收集网页内容或视频时间点的人。 |
| 划线 | 用户从网页正文中选中的文字片段及其来源页面信息。 |
| 视频打点 | 用户在支持的视频页面记录的当前播放时间点及视频信息。 |
| 页面 | 以 URL 归属的内容集合，包含该 URL 下的划线和视频打点。 |
| 笔记 | 用户附加在划线或视频打点上的文字说明。 |
| 剪藏库 | 侧边栏中按页面归档展示划线和视频打点的内容集合。 |

## INVEST 自检

| 原则 | 检查结果 |
|---|---|
| Independent | 按首次使用、网页划线、视频打点、剪藏库、导出与数据拆分，文件之间保持低耦合。 |
| Negotiable | 只描述用户目标和可观察结果，不绑定 DOM、消息协议或存储字段。 |
| Valuable | 每条故事对应收集、回顾、整理、迁移或数据安全价值。 |
| Estimable | 每条故事边界清晰，便于独立估算。 |
| Small | 将笔记、定位、去重、删除等独立能力继续拆分。 |
| Testable | 每条故事均有配对的 Acceptance Criteria，并覆盖边界场景。 |

当前代码描述中提到的“标签整理”尚未形成创建、编辑、筛选和持久化闭环，因此不纳入本版本 User Story。

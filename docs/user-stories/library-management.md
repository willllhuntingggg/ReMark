# 剪藏库管理 User Stories

## US-11：按页面归档查看剪藏内容

**User Story**  
作为用户，我希望按来源页面查看划线和视频打点，以便理解每组内容的上下文。

**Acceptance Criteria**

- **Given** 存在来自一个或多个页面的划线或视频打点，**When** 用户打开剪藏库，**Then** 内容按来源 URL 分组展示。
- **Given** 一个页面同时存在划线和视频打点，**When** 用户查看该页面分组，**Then** 两类内容都归属于同一页面分组。
- **Given** 多个页面分组存在，**When** 用户查看剪藏库，**Then** 页面分组按最近一次内容创建时间从新到旧排列。

## US-12：搜索划线和笔记

**User Story**  
作为用户，我希望搜索原文、笔记或页面标题，以便从剪藏库中快速找到相关内容。

**Acceptance Criteria**

- **Given** 用户输入搜索词，**When** 搜索条件发生变化，**Then** 结果只保留原文、划线笔记或页面标题包含该词的页面内容。
- **Given** 搜索词大小写与已保存内容不同，**When** 用户执行搜索，**Then** 匹配结果不受英文字母大小写影响。
- **Given** 用户清空搜索条件，**When** 清空完成，**Then** 剪藏库恢复展示全部页面内容。
- **Given** 页面只有视频打点而没有划线，**When** 用户搜索，**Then** 该页面仍按当前代码规则保留在结果中；视频打点本身不参与文本搜索匹配。

## US-15：删除一个页面的全部剪藏

**User Story**  
作为用户，我希望一次删除某个来源页面的全部剪藏，以便清理整组无用内容。

**Acceptance Criteria**

- **Given** 一个页面存在一条或多条划线和/或视频打点，**When** 用户删除该页面，**Then** 该 URL 归属的所有划线和视频打点都从剪藏库中移除。
- **Given** 被删除页面当前在浏览器中打开，**When** 删除完成，**Then** 页面中的 ReMark 高亮被移除。
- **Given** 其他页面存在剪藏，**When** 用户删除一个页面，**Then** 其他页面的内容不受影响。

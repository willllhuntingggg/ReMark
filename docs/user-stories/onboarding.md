# 首次使用 User Stories

## US-01：打开剪藏侧边栏

**User Story**  
作为用户，我希望在浏览网页时打开 ReMark 侧边栏，以便查看和管理已经保存的内容。

**Acceptance Criteria**

- **Given** 用户正在使用 ReMark 扩展，**When** 用户点击扩展图标，**Then** 当前浏览器窗口打开 ReMark 侧边栏。
- **Given** 侧边栏已打开，**When** 用户重新加载或再次打开侧边栏，**Then** 侧边栏能够读取并展示已有剪藏内容，而不是只展示本次会话新增内容。

## US-03：首次使用时学习快捷键划选

**User Story**  
作为首次使用 ReMark 的用户，我希望看到一个简短的快捷键划选教学动画，以便理解如何通过按住 Command 或 Ctrl 并划选文字来创建划线。

**Acceptance Criteria**

- **Given** 用户首次打开 ReMark 且尚未完成快捷键划选，**When** 教学入口出现，**Then** 系统展示“按住 Command/Ctrl 并划选文字”的教学内容，并包含可理解的动态演示。
- **Given** 教学动画正在展示，**When** 用户查看教学内容，**Then** 动画表达完整的操作顺序：选择文字、按住快捷键、完成划选并产生高亮结果。
- **Given** 用户已经完成过快捷键划选教学或明确关闭教学，**When** 用户再次使用 ReMark，**Then** 系统不重复强制展示该教学。
- **Given** 教学动画无法播放，**When** 用户进入首次使用引导，**Then** 系统仍以静态文字或图示说明快捷键划选方式，不影响用户继续使用。

# 视频打点 User Stories

## US-07：在支持的视频页面记录时间点

**User Story**  
作为用户，我希望在 YouTube 或 Bilibili 视频播放过程中记录当前时间点，以便以后直接回到关键片段。

**Acceptance Criteria**

- **Given** 用户位于可识别的视频页面且视频元素可用，**When** 用户通过页面中的“打点”能力或 Command/Ctrl+M 记录时间，**Then** 系统保存当前播放时间、视频标识、视频标题、页面 URL 和视频总时长（若可获得）。
- **Given** 当前页面不是受支持的视频页面，**When** 用户尝试使用视频打点快捷方式，**Then** 系统不创建视频打点。
- **Given** 视频当前时间不可用或不是有效的非负时间，**When** 用户触发打点，**Then** 系统不创建视频打点。

## US-08：避免同一视频的近重复打点

**User Story**  
作为用户，我希望重复记录同一视频的相近时间点时不会产生重复内容，以便保持打点列表清晰。

**Acceptance Criteria**

- **Given** 同一视频已有一个打点，且已有打点与当前时间相差小于 1 秒，**When** 用户再次记录，**Then** 系统不新增打点，并将视频定位到已有时间点。
- **Given** 当前时间与同一视频已有打点相差至少 1 秒，**When** 用户记录，**Then** 系统新增一条独立视频打点。
- **Given** 两个打点属于不同视频，**When** 它们的时间相近，**Then** 一个视频的打点不阻止另一个视频创建打点。

## US-09：查看和使用视频打点

**User Story**  
作为用户，我希望在视频进度条和剪藏库中看到视频打点，以便快速回到关键时间点。

**Acceptance Criteria**

- **Given** 当前视频存在已保存打点，**When** 视频页面加载且进度条可用，**Then** 对应打点在进度条的相对时间位置显示。
- **Given** 用户点击视频进度条上的某个打点，**When** 定位操作执行，**Then** 视频跳转到该打点时间；若视频暂停，系统可以继续播放。
- **Given** 用户从剪藏库打开某个视频打点，**When** 来源视频页面已打开，**Then** 系统激活该页面并将视频定位到打点时间；若页面未打开，则打开带有时间参数的来源页面。

## US-10：为视频打点添加或修改笔记

**User Story**  
作为用户，我希望为视频打点记录评语，以便说明该时间点的价值或后续行动。

**Acceptance Criteria**

- **Given** 用户拥有一个视频打点，**When** 用户保存一段笔记，**Then** 该笔记与该视频打点关联，并在剪藏库中显示。
- **Given** 视频打点已有笔记，**When** 用户保存新的笔记内容，**Then** 原笔记被替换，时间点、视频和来源信息不变。
- **Given** 用户保存空白笔记，**When** 保存完成，**Then** 系统移除该打点的笔记内容。

## US-14：删除单个视频打点

**User Story**  
作为用户，我希望删除不再需要的视频打点，以便保持视频回顾路径准确。

**Acceptance Criteria**

- **Given** 剪藏库或视频页面中存在一个视频打点，**When** 用户删除该打点，**Then** 该打点从剪藏库和对应视频进度条中移除。
- **Given** 同一视频存在多个打点，**When** 用户删除其中一个，**Then** 其他打点仍可查看和定位。
- **Given** 视频页面当前打开，**When** 删除完成，**Then** 页面上的打点展示会刷新为最新状态。

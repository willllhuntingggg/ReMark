# 网页划线 User Stories

## US-02：通过选中文字创建划线

**User Story**  
作为用户，我希望在网页中选中一段文字并保存，以便保留值得回看的原文片段。

**Acceptance Criteria**

- **Given** 当前网页存在至少 2 个字符的可见文字选择，**When** 用户按住 Command 或 Ctrl 完成选择，**Then** 系统保存一条划线，并记录原文、页面 URL、页面标题、创建时间和默认颜色。
- **Given** 用户完成一次有效划线，**When** 保存成功，**Then** 原文片段在当前页面以高亮形式显示，并能在剪藏库中找到。
- **Given** 用户选择为空、少于 2 个字符或没有有效可见区域，**When** 用户使用快捷方式，**Then** 系统不创建划线。

## US-04：恢复网页中的历史划线

**User Story**  
作为用户，我希望重新访问曾经划线的网页时看到历史高亮，以便快速恢复阅读上下文。

**Acceptance Criteria**

- **Given** 剪藏库中存在某页面的划线，**When** 用户打开该页面或页面在不完整刷新中切换到新的 URL，**Then** 系统尝试在页面正文中恢复对应高亮。
- **Given** 历史划线的原文能够在当前页面正文中匹配，**When** 页面恢复完成，**Then** 该片段显示为与原划线关联的高亮。
- **Given** 历史划线的原文无法在当前页面正文中匹配，**When** 页面恢复完成，**Then** 页面内容不被替换，且该划线仍保留在剪藏库中。

## US-05：查看和定位划线

**User Story**  
作为用户，我希望从剪藏库定位一条划线，以便回到来源页面继续阅读原文。

**Acceptance Criteria**

- **Given** 剪藏库中存在一条划线，**When** 用户选择该划线的打开或定位操作，**Then** 系统激活对应来源页面；若页面未打开，则打开该来源页面。
- **Given** 来源页面已加载且原文可匹配，**When** 定位操作完成，**Then** 页面滚动到该划线，并对目标片段提供短暂的视觉提示。
- **Given** 目标片段尚未恢复，**When** 用户执行定位，**Then** 系统先尝试恢复页面高亮，再继续定位。

## US-06：为划线添加或修改笔记

**User Story**  
作为用户，我希望为一条划线记录自己的想法，以便在以后复习时理解当时的判断。

**Acceptance Criteria**

- **Given** 用户拥有一条划线，**When** 用户保存一段笔记，**Then** 该笔记与这条划线关联，并在剪藏库中显示。
- **Given** 划线已有笔记，**When** 用户保存新的笔记内容，**Then** 原笔记被新的内容替换，且划线本身的原文和来源不变。
- **Given** 用户提交空白笔记，**When** 保存完成，**Then** 系统将该划线视为没有笔记，并显示可再次添加笔记的状态。

## US-13：删除单条划线

**User Story**  
作为用户，我希望删除不再需要的划线，以便保持剪藏库准确。

**Acceptance Criteria**

- **Given** 剪藏库中存在一条划线，**When** 用户删除该划线，**Then** 该划线从剪藏库中移除。
- **Given** 该划线当前已在来源页面显示，**When** 删除完成，**Then** 页面中的对应高亮也被移除，而页面原文保持可读。
- **Given** 同一页面还有其他划线或视频打点，**When** 用户删除一条划线，**Then** 其他内容不受影响。

ReMark

Mark it now. Find it later. — 本地优先的划线、笔记与视频打点收集工具。

Chrome Extension · Manifest V3 · 数据仅保存在本地

快速测试引导

  1. 用鼠标选中下方任意一段文字，体验 按住 ⌘/Ctrl 后划选并高亮 的保存方式。
  2. 点击页面中的高亮文字，在侧边栏中定位对应的 Mark，并为其添加笔记。
  3. 在 YouTube 或 Bilibili 视频播放到关键位置时，按 ⌘/Ctrl+M 记录视频打点。
  4. 打开 ReMark 侧边栏：查看 Mark 时间流、搜索、按来源浏览，并多选页面导出 Markdown。

深度测试段落 1：为什么信息整理需要“卡片化”与“评语”？

在进行行业调研或深度学习时，简单的“收藏夹”往往会沦为知识的坟场。真正的认知提升发生于 划线提炼 与 撰写评语思考 的瞬间。通过在看到有启发的内容时快速高亮， 并用一两句话记录下自己的见解，能够将外部信息转化为个人知识库。

Mark it now. Find it later. —— ReMark 设计理念

深度测试段落 2：让收集的知识能被二次唤醒

收集本身不是目的，二次唤醒 才是。当你为一段划线补上自己的想法， 它就从一个孤立的片段变成了可检索、可复用的知识节点。配合视频打点（ ⌘/Ctrl+M 记录关键时间点）与批量导出 Markdown， 你可以在任意工具中继续沉淀与使用这些内容。

深度测试段落 3：全本地数据存储与统一归档

ReMark 基于 Chrome 扩展程序原生的 #chrome.storage.local 运行， 所有划线快照、评语笔记与视频打点均保存在你的本地浏览器中， 不需要任何后台服务器，隐私安全且毫秒级快速响应。

🚀 快速测试引导：

  1. 用鼠标选中本页面下方的任意一段文字，体验浮动工具栏弹出。
  2. 点击颜色按钮进行高亮，或点击 📝 写想法 按钮写入思考与 #标签。
  3. 点击右侧或者插件图标打开 ReMark 侧边栏 (Sidepanel)，查看剪藏库中的划线、想法与视频打点，并可多选页面导出 Markdown 文档。

深度测试段落 1：为什么信息整理需要“卡片化”与“评语”？

在进行行业调研或深度学习时，简单的“收藏夹”往往会沦为知识的坟场。真正的认知提升发生于划线提炼与撰写评语思考的瞬间。通过在看到有启发的内容时快速高亮，并用一两句话记录下自己的见解，能够将外部信息转化为个人知识库。

"Mark it now. Find it later." —— ReMark 设计理念

深度测试段落 2：让收集的知识能被二次唤醒

收集本身不是目的，二次唤醒才是。当你为一段划线补上自己的想法与标签，它就从一个孤立的片段变成了可检索、可复用的知识节点。配合视频打点（⌘M 记录视频关键时间点）与批量导出 Markdown，你可以在任意工具中继续沉淀与使用这些内容。

深度测试段落 3：全本地数据存储与统一归档

ReMark 基于 Chrome 扩展程序原生的 #chrome.storage.local 运行，所有划线快照、评语笔记与视频打点均保存在你的本地浏览器中，不需要任何后台服务器，隐私安全且毫秒级快速响应。

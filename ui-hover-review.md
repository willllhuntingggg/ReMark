# Mark Card Hover Review

The hover selector is attached to `.mark-card`, rather than the text button, so it covers the complete row including its non-text whitespace, note area, footer and action area. The selected-state selectors override the generic Slate hover wash with a warmer gold-tinted background, preserving a distinct range-selection hierarchy.

Native side panel width should be confirmed after extension reload because the browser file preview renders the panel document at desktop width.
